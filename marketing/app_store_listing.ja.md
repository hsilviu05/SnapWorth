# App Store Listing — 日本語 (Japanese)

Metadata for the `jp` storefront, written for **1.8.1**, the first build whose app
speaks this language. A localized listing ships with the localized binary,
never ahead of it (root `CLAUDE.md`): add this locale to the 1.8.1 version
page only, and paste every field below.

Mirrors `app_store_listing.md`, including its accuracy rules: no claim of sold
listings, comps or market data; no word for "accurate" or "exact" about the
estimate; the one-scan-a-day limit in every plan mention; "unlimited" only
with its fair-use qualifier; confidence as a band, never a score. The full
list is in the English file, under *Claims this listing does not make*.

**Voice.** Polite です/ます, as the app says throughout. A flip is リセール, never 転売, which reads as scalping in Japan.

**Feature names match the app.** A find is お宝 (マイお宝), a flip リセール (マイリセール); Haul mode is まとめスキャン, Rack scan ラックスキャン, Legit check 本物チェック, and Why this price 「この価格の理由」. "Thrift Flip", "Snap → Sell" and
"Ask Tag" are names, the same in every language.

**Prices.** No figure appears: each storefront's price is Apple's own tier in
its own currency.

**Values are in dollars.** The estimate is in USD whatever the region; since
1.8.0 a line under it restates the range in the phone's currency, labelled as
a conversion. The description says both.

**Japanese is the riskiest of the six** to ship without a native reader: Japanese users notice machine-sounding copy at once. Get this read before pasting if anyone can.

## Description (4000 chars max)

古着屋で手に取ったもの、本当に価値があるのか気になったことはありませんか？SnapWorthなら数秒で分かります。

中古品（ジャケット、スニーカー、ヴィンテージカメラ、ブランドバッグなど）にカメラを向けるだけで、AIがアイテムを識別し、リセール価格を価格帯と信頼度で査定します。

衣類、靴、アクセサリー、家電・電子機器、本、家具、インテリア・生活、スポーツ、おもちゃ、コレクション。

--------------------------

使い方

1. 中古品にカメラを向ける
2. シャッターを押す、またはライブラリから写真を選ぶ
3. AIのリセール査定が表示される
4. 用意された出品文をコピーして、今日出品

--------------------------

できること

• すぐ分かるリセール価格：下限から上限までの推定価格帯
• 信頼度（高・中・低）：写真と識別がどれだけ査定を裏付けているか
• AIが書く出品文：スキャンごとに、そのまま使えるタイトルと説明文
• Thrift Flip：アイテムをスキャンして店頭価格を入れると、買う前にマーケット手数料を引いた利益が分かります
• あなたの通貨：ドルの価格帯の下に、現地通貨への換算を表示
• 履歴：見つけたお宝を価値とともに自動保存
• ウィジェット：ロック画面に収穫の合計、ホーム画面に最近のお宝、無料スキャンの残り、今日の値当て
• 今日の値当て：1日1点、リセール価格を予想。スキャンは使いません
• SnapWorthに共有：どのアプリからでも写真やスクリーンショットを共有して価値をチェック
• Ask Tag：マスコットのTagに、価格や売る場所、出品文について週1回無料で質問

--------------------------

こんな方に

• 古着屋、リサイクルショップ、フリーマーケットめぐりが好きな方
• メルカリ、ラクマ、ヤフオク、eBayで売っている方
• 「これ、買う価値ある？」と思ったことのあるすべての方

--------------------------

無料とPro

SnapWorthはアカウント不要で無料で使えます。毎日1回の無料スキャンはずっと続きます。お宝は価値とともにスマホに保存され、課金してもしなくても履歴はあなたのものです。

Proでは：
• 無制限スキャン（適正利用の範囲内）
• まとめスキャン：次々に撮るだけで1点ずつ査定、合計もリアルタイム表示
• ラックスキャン：ラック、棚、カゴを1枚撮るだけで要チェックのアイテムを表示
• 本物チェック：ガイド付きの接写で、よくある偽物のサインを確認。写真についての所見であり、真贋の証明ではありません。
• 選んだマーケット向けに書き直した出品文
• 「この価格の理由」：査定の詳しい内訳
• タグの読み取り：タグを撮影して査定を絞り込み
• お宝ごとのTagのヒントと、週の上限なしのAsk Tag
• コレクション価値の推移と古着トレンド
• 利益の記録：購入額、売れた価格、手数料を引いた利益。CSV書き出し対応

月額または年額。年額には無料トライアルがあり、期間は登録前に表示されます。iPhoneの設定からいつでも解約できます。

--------------------------

プライバシー

最初のスキャンの前に、分析のためGoogle Geminiに送る内容を表示し、同意をお願いします。Googleはモデルの学習に使わず、私たちも回答後に写真を保持しません。履歴はスマホに残ります。データを販売することはありません。

価格は米ドルで査定されます。
