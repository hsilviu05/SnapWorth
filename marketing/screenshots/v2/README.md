## Known limitations of the generated frames

- **Bezel is drawn, not photographic.** Clean and flat rather than a
  photorealistic titanium rail. A designer should swap in a proper device
  mockup — the layout geometry is already correct, so it is a straight
  replacement.
- **Frame 6 shows one item.** A real history screenshot needs 6–10 varied
  finds. Populate a device and re-capture.
- **Frame 1's hero photo is on a white background**, so the top third of the
  result sheet reads empty. A photo shot against a darker or textured ground
  would fill it better.

## Regenerating

```bash
xcrun simctl boot "iPhone 16 Pro Max"
xcrun simctl status_bar <UDID> override --time 9:41 \
  --batteryLevel 100 --batteryState charged --cellularBars 4 --wifiBars 3
xcrun simctl ui <UDID> appearance light
# capture screens to /tmp/snapshots/raw_NN_*.png
python marketing/build_screenshots.py
```

Layout, type and colour values live in `build_screenshots.py` and match
`SCREENSHOT-HANDOFF.md`. Change them in one place.
